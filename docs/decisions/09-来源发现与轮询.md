# 决策 09：服务来源采用"静态配置 + 轮询"，不引入注册中心

日期：2026-10-20　状态：已采纳

## 背景

平台需要知道"有哪些业务系统、它们的 OpenAPI 契约在哪"。这件事可以拆成两个独立问题：

1. **来源发现**：平台从哪里得到来源清单和地址；
2. **契约对账**：拿到地址后，如何把 OpenAPI 变成工具并持续收敛（决策 08）。

当前实现只覆盖第 2 件：来源写在 `platform.gateway.sources`，平台启动时读配置，之后每 5 分钟主动 `GET /v3/api-docs`。讨论中反复出现两个疑问：为什么不学 Nacos 用长连接/推送？为什么不能由管理员在管理端直接新增来源？

## 备选方案

| 方案 | 及时性 | 对业务系统的要求 | 代价 | 适用场景 |
|---|---|---|---|---|
| **静态配置 + 轮询（当前）** | 默认 5 分钟 | 无，只要暴露契约 | 配置变更需重启；空转请求 | 来源少、地址稳定、接入是低频运维事件 |
| DB 注册表 + 轮询 | 5 分钟 | 无 | 多一套来源 CRUD、凭证入库与掩码 | 需要管理员自助接入、免重启 |
| Webhook + 轮询兜底 | 秒级 | 业务侧发布流程要回调平台 | 回调鉴权、重试、幂等；漏事件仍需轮询 | 发版频繁、要求新接口近乎即时可用 |
| Nacos / Consul 服务发现 | 秒级 | 业务进程引入客户端并注册，或由部署侧代注册 | 多一套中间件与控制面；与"业务系统对 AI 零感知"冲突 | 服务数量多、实例地址频繁变化 |
| 长连接推送（自研） | 秒级 | 同上，或平台与每个后端维持会话 | 心跳/重连/半开连接/多实例连接管理 | 高频变更的注册中心型场景 |

## 决策

1. **来源清单由配置提供，平台主动拉契约**。`platform.gateway.sources[].id` 是稳定归属键，`url` 指向 `/v3/api-docs`。
2. **采用轮询而非长连接/推送**，理由按重要性排列：
   - **变更源不在业务系统进程内**：监听的是 `/v3/api-docs` 的内容，springdoc 不会发"契约已变更"事件。要推送，就得给每个业务系统加 webhook、鉴权与重试，等于把接入成本从"给一份文档"抬到"按平台框架改代码"，直接违反 决策 07 的零改造前提。
   - **拉模型天然自愈**：平台重启、网络闪断、漏掉一轮，下一轮自动收敛。推模型必须自己解决事件丢失、乱序、重复与平台离线期间变更——这些正是注册中心客户端 SDK 的职责，而本项目刻意不引入 SDK。
   - **频率与代价不匹配**：契约只在发版时变化，3 个来源每 5 分钟一轮约等于每分钟 0.6 次 GET；契约未变时哈希比对后直接跳过，不写库、不刷新缓存。长连接省下的延迟没有业务价值，却要维护连接状态、心跳与重连。
   - **模拟协议在面试中是负资产**：被追问 Nacos 的 AP/CP、临时/持久实例、心跳续约时，自研模拟版答不上来，反而不如诚实说明"当前规模不需要，留了演进路径"。
3. **轮询只是"触发对账"，不是一致性来源**。真正的期望状态始终是契约本身；启动对账、定时对账、手工触发共用 `ContractSyncService.sync` 这一条路径，任何入口都不改变对账语义。
4. **演进路径明确，但不提前实现**：
   - 第一步（需要管理员自助接入时）：把来源定义从配置搬进 `tool_source`，配置文件只做启动种子，新增 `POST/PUT/DELETE /admin/sources`；服务凭证入库后必须掩码返回。**已于 2026-10-20 实施**。
   - 第二步（需要及时性时）：CI 发布成功后调用 `POST /admin/sources/{sourceKey}/sync` 做 webhook，**轮询继续保留作为兜底**——工业界的 watch + 定期 resync 是同一形态。
   - 第三步（服务数量与实例变化超出人工维护能力时）：在发现层接 Nacos/Consul，对账层不变。
5. **多实例不在本决策范围内**。多实例下的重复抓取、缓存刷新与确认项归属见 决策 08 第 9 条；触发条件是真正部署多个副本或滚动发布窗口无法接受。

## 后果

**正面**

- 业务系统零改造：不装 SDK、不注册、不回调，只需保持 `/v3/api-docs` 可访问；
- 对账天然自愈，平台与业务系统之间没有需要维护的长连接状态；
- 三个触发点共享一条路径，行为可预测、可测试；
- 演进方向清晰：发现层与对账层解耦，换发现方式不触碰对账逻辑。

**负面 / 代价**

- 新增来源需要改配置并重启平台（当前最大的体验缺口）；
- 从配置移除来源后，其名下工具不会自动下线，需要手工禁用或实施来源生命周期收敛；
- 默认 5 分钟的最终一致窗口，排障时要记得看 `GET /admin/sources` 的 `lastSuccessAt`；
- 轮询会周期性请求未变化的契约（代价可忽略，但不是零）。
